# AlpicAir — sienas kondicionieri

Showroom wall of AlpicAir wall-mounted air conditioners (Latvian). Product photos and data from alpicair.com.

- `npm install && npm run dev` — local preview
- `npx vite build --outDir docs --emptyOutDir && touch docs/.nojekyll` — rebuild the published site; GitHub Pages serves `docs/` on `main`
